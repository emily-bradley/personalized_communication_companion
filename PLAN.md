## Stack (decided)

- SwiftUI, iOS 17 minimum, Swift 5.10+ / Xcode 16 on CI.
- Project generated by **XcodeGen** from `project.yml` (text only, so it can be edited from Linux). Do not commit a hand-edited `.xcodeproj`; generate it in CI.
- `SelvoCore`: a local Swift package (models, stores, suggestion providers, theme tokens) with no UIKit or SwiftUI imports, so `swift test` runs on Linux too.
- `Selvo` app target: SwiftUI views only, depends on SelvoCore.
- Persistence: JSON files in Application Support via a small `Store` (no CoreData, no SwiftData for the demo).
- Speech: `AVSpeechSynthesizer`. Listening: `Speech` framework (`SFSpeechRecognizer`) with on-device recognition when available.
- Suggestions: `SuggestionProvider` protocol. Implement `SavedPhraseProvider` (offline, templates keyed by tile and style tag). Add `FoundationModelsProvider` behind `#if canImport(FoundationModels)` and an availability check; fall back to saved phrases silently.
- CI: GitHub Actions on `macos-15`: `brew install xcodegen`, `xcodegen`, `xcodebuild build test` on an iPhone 16 simulator, and a screenshot test that saves PNGs of every screen in both themes as a workflow artifact. The repo is public, so macOS minutes are free.
- Fonts: Lexend (400, 600) and Atkinson Hyperlegible bundled from Google Fonts (OFL). Commit the license files.
