# Selvo

Your voice. Your way.

Selvo is a communication companion for non-verbal adults. It learns how you like to say things and offers words that sound like you, through pictures, context, and choices you control.

This repository holds the native iPhone app (SwiftUI), in progress. The earlier Flutter prototype is preserved in `legacy/flutter-prototype/` and on branch `prototype-2025`.
