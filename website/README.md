# Selvo website

Marketing site for Selvo, a communication companion for non-verbal adults.

```sh
pnpm install
pnpm dev        # http://localhost:4321
pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm e2e
```

Screenshots from `pnpm e2e` land in `screenshots/`. Deploy steps are in `docs/DEPLOY.md`. Agent rules are in `CLAUDE.md`.
